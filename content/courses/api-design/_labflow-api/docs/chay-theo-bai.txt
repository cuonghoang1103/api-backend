LabFlow API — cuối Chương 10 khoá API Design (cuongthai.com/courses/api-design)
Chỉ để HỌC. Mật khẩu demo: an-lab-2026, binh-lab-2026, lan-lab-2026.

  npm install
  npm start                      # không cần PostgreSQL/Redis (việc nền chạy trong RAM: LABFLOW_JOBS=memory)
  npm test                       # 13 test

Cần cho Chương 9–10: PostgreSQL 18 ở PGURL (mặc định postgres://labflow@localhost:55432/labflow, có bảng bookings
1 triệu dòng của Chương 3) và Redis 8.2 ở LABFLOW_REDIS (mặc định redis://localhost:6390).
