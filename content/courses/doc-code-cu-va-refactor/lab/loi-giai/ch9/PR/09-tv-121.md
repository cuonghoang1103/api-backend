## [TV-121] Java 17 → 21 LTS (build và chạy)

### 1. Nguyên nhân gốc
Máy chủ mới của khách chuẩn hoá JDK 21 từ tháng 12.

### 2. Phạm vi ảnh hưởng
Code: pom (release 21, enforcer [21,), PMD targetJdk 21), Dockerfile (maven:3.9-eclipse-temurin-21 → tomcat:10.1-jdk21-temurin), NANG-CAP.md mốc 4. Máy dev: cần JDK 21 — enforcer chặn JDK 17 ngay từ đầu.

### 3. Cách kiểm
JDK 17: BUILD FAILURE "Detected JDK version 17.0.20-1 … not in the allowed range [21,)". JDK 21: 61/61, e2e, golden master giống hệt.

### 4. Rủi ro / đường lùi
JDK 25 là mốc kế (Locale COMPAT bị gỡ). Đường lùi: revert một commit (ảnh và release về 17).
