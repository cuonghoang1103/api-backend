# Chi làm 2 commit trên main và PUSH luôn (main không có luật bảo vệ)
[Chi] $ git commit -qam "Login bang email"
[Chi] $ git commit -qam "index: nut dang nhap"
[Chi] $ git push origin main
To <LAB>/github.git
   a9576f4..a6db29f  main -> main

# An pull và nhận luôn việc dở dang của Chi
[An] $ git pull -q
[An] $ git log --oneline -3
a6db29f index: nut dang nhap

a9576f4 Khoi tao du an NetBeans: Login, Home, web.xml
