# Bảng đánh giá phù hợp & quyết định go/no-go (Qualification Scorecard)

> **Mục đích:** quyết định có theo đuổi dự án hay không theo tiêu chí viết sẵn, thay vì cảm tính — và ghi lại lý do.
> **Ai điền:** Kinh doanh / Presales chấm; Kiến trúc giải pháp, PM, Pháp lý đóng góp; PMO quyết định.
> **Khi nào:** sau buổi tư vấn đầu tiên, trước khi cam kết khảo sát.
> **Giai đoạn:** 01 · Tiền bán hàng & đánh giá phù hợp (Presales & qualification).

## 2. Chấm điểm (0 = không đạt · 1 = chưa rõ · 2 = đạt)

| # | Tiêu chí | Câu hỏi kiểm | Điểm | Bằng chứng / ghi chú |
|---|---|---|---|---|
| 1 | Nhu cầu (Need) | Vấn đề có thật, có người chịu đau, đo được lợi ích? | | |
| 2 | Ngân sách (Budget) | Khoảng ngân sách khả thi cho phạm vi đã nghe? | | |
| 3 | Thẩm quyền (Authority) | Người quyết định đã tham gia hoặc được báo? | | |
| 4 | Thời hạn (Timeline) | Hạn chót khả thi với nguồn lực hiện có? | | |
| 5 | Phù hợp kỹ thuật | Công nghệ nằm trong năng lực của đội / có người đồng hành? | | |
| 6 | Năng lực & lịch | Có người sẵn sàng đúng thời điểm, không xung đột dự án khác? | | |
| 7 | Rủi ro pháp lý / dữ liệu | Dữ liệu cá nhân, ngành có quản lý, lưu trữ trong nước đã rõ? | | |
| 8 | Xung đột lợi ích | Không làm cho đối thủ trực tiếp của khách hiện tại? | | |
| 9 | Đạo đức & mục đích sử dụng | Sản phẩm không phục vụ mục đích trái pháp luật / gây hại? | | |
| 10 | Quan hệ lâu dài | Có khả năng bảo trì / giai đoạn tiếp theo? | | |
| | **Tổng** | | **/20** | |

**Quy tắc gợi ý:** tiêu chí 7, 8, 9 đạt 0 ⇒ **từ chối** bất kể tổng điểm. Tổng ≥ 15 ⇒ go; 10–14 ⇒ go có điều kiện; < 10 ⇒ no-go.
