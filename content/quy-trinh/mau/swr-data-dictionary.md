# Data Dictionary for <Project>

> **Purpose:** SWR302 Deliverable 5 — the shared definition of every data element the use cases and the SRS use: meaning, composition or data type, length and allowed values. Every noun used in a use case flow must have an entry here (link #4).
>
> **Guide:** follows Wiegers' *Guidance for Data Dictionaries* (chapter 13). A **primitive** element has a data type, a length and allowed values. A **data structure** is composed of other elements separated by "+"; leave Length and Values blank. Optional elements go in parentheses "(Vendor)"; a repeating group is "min:max{Item}" ("n" = no upper limit); literal text goes in quotes. Every item that appears in a structure must itself be defined. "Fill from project data" writes the dictionary of Requirements → Wiegers → Data dictionary.
