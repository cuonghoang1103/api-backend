# Business Rules for <Project>

> **Purpose:** SWR302 Deliverable 3 — the business rules catalog (BR-nn), each classified into one of Wiegers' five types (chapter 9) with whether it is static or dynamic and where it came from. Use cases cite these rules by ID only.
>
> **Guide:** layout follows the "Business Rules for Cafeteria Ordering System" example of the book (Appendix C). Types: **Fact** (a true statement about the business), **Constraint** (restricts an action), **Action enabler** (triggers an activity when a condition is true), **Inference** (derives new knowledge), **Computation** (a formula). Static = unlikely to change; dynamic = expected to change. "Fill from project data" writes the rules of Requirements → Business rules.
