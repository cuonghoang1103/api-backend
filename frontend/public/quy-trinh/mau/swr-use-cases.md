# Use Case Field Guidance

## Use Case ID and Name

> **Guide:** give each use case a unique sequence number (UC-nn) and a concise name that states the value it provides: an action verb followed by an object ("Place Order").

## Author and Date Created

> **Guide:** the person who first wrote the use case and the date it was written.

## Primary and Secondary Actors

> **Guide:** the primary actor initiates the use case; secondary actors participate in it. Actors are people or external systems; different actors often correspond to different user classes.

## Trigger

> **Guide:** the business event, system event or user action that starts the use case.

## Description

> **Guide:** a brief description of the reason for and the outcome of the use case.

## Preconditions

> **Guide:** conditions the system can test that must be true before the use case starts — PRE-1, PRE-2…

## Postconditions

> **Guide:** the state of the system after successful completion — POST-1, POST-2…

## Normal Flow

> **Guide:** the numbered dialog of user actions and system responses under normal, expected conditions, leading to the goal in the use case name.

## Alternative Flows

> **Guide:** other successful scenarios, numbered X.Y (use case X, alternative Y), naming the normal-flow step where each branches and where it rejoins.

## Exceptions

> **Guide:** anticipated error conditions and how the system responds, numbered X.Y.EZ.

## Priority

> **Guide:** High, Medium or Low — the same scheme used for the functional requirements.

## Frequency of Use

> **Guide:** how often the use case is performed per unit of time — an early indicator of load and capacity.

## Business Rules

> **Guide:** the IDs of the business rules that influence this use case (BR-nn) — never the rule text.

## Other Information

> **Guide:** quality attributes, related functional requirements that are not part of the flows, and what happens if the use case fails for a systemic reason.

## Assumptions

> **Guide:** assumptions made about this use case or how it executes.
